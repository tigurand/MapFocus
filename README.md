# MapFocus

Just a simple plugin with 2 functions you can toggle:
1. Stop the map from centering on you.
2. Center the map when it opens. (Also have a button and command to manually center the map)

# Installation

Add<br />

```
https://raw.githubusercontent.com/tigurand/DalamudPlugins/refs/heads/main/repo.json
```

to list of custom repo under Experimental tab in Dalamud settings.  
Install and enable MapFocus.
